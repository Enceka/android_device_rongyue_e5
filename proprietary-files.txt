#   /vendor_dlkm/**                 rebuilt by the in-tree kernel (see modules.load)
#   /system/** (rest), /product/**  rebuilt from LineageOS sources
#   build.prop, fs_config_*, passwd, group, NOTICE.xml.gz, etc/vintf/*,
#   etc/selinux/**                  regenerated by the Android build (see README.md)

# Trimmed against the running device:
#   * ISP tuning firmware for the 10 sensor modules this board never probes
#     (logcat: gc5035_back -> sp5508 on slot 0 and sc201mcs -> c2599 on slot 1;
#      only the second probe of each pair ever succeeds),
#   * libsensor_*.so for the modules that are never present,
#   * charger animation frames for the resolutions this 320x480 panel never uses.
#
# Trimmed because the ROM builds them itself (shipping a prebuilt at the same
# destination as a build output makes ninja fail with 'multiple rules generate',
# or silently shadows the module the product resolved):
#   * build/make/target/product/base_vendor.mk, which always installs its
#     modules into $(TARGET_COPY_OUT_VENDOR),
#   * system/core/shell_and_utilities (shell_and_utilities_vendor) -> /vendor/bin,
#   * external/wpa_supplicant_8 (wpa_supplicant, hostapd and their libraries),
#   * the apps under system_ext that packages/apps and frameworks/base provide,
#   * the AOSP HAL implementations (hardware/interfaces, hardware/libhardware,
#     frameworks/av) and the HIDL/AIDL interface libraries they install.
#
